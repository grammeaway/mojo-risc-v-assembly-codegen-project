# Notes from going through the "exercise"

## Step 1: Set up environment

We'll be working within the Python toolchain (MOJO is a Python superset), so we'll need to set up a Python environment. I always turn to `uv` for this, but you can use whatever you like.

Usving `uv`, install MOJO:

```bash
uv add mojo
```

## Step 2: Hello World in MOJO 
Let's start with a simple "Hello, World!" program in MOJO. This will give us a baseline to analyze the generated RISC-V machine code.

```python
fn main():
    print("Hello, Mojo!")
```

To run it on just your local machine, you can use the `mojo run` command:

```bash
uv run mojo run hello_world.mojo
```

And that should print "Hello, Mojo!" to the console. Now we have a simple MOJO program that we can compile to RISC-V machine code and analyze.

## Step 3: Figuring out your MOJO compile command arguments

MOJO supports a wide array of compilation targets, and the low-level performance focus of the language, has led to the maintainers allowing very fine-grained control over the compilation process. To compile for e.g. RISC-V, you need to both configure a triple, and a target CPU architecture. The triple is a string that describes the target platform, and the target CPU architecture is a string that describes the specific CPU architecture you want to compile for.

To get a list of available triples, you can use the `mojo  build --print-supported-targets` command:

```bash
 uv run mojo build --print-supported-targets
Registered Targets:
  xtensa - Xtensa 32
  x86-64 - 64-bit X86: EM64T and AMD64
  x86 - 32-bit X86: Pentium-Pro and above
  riscv64be - 64-bit big endian RISC-V
  riscv32be - 32-bit big endian RISC-V
  riscv64 - 64-bit RISC-V
  riscv32 - 32-bit RISC-V
  nvptx64 - NVIDIA PTX 64-bit
  nvptx - NVIDIA PTX 32-bit
  hexagon - Hexagon
  amdgcn - AMD GCN GPUs
  r600 - AMD GPUs HD2XXX-HD6XXX
  aarch64_32 - AArch64 (little endian ILP32)
  aarch64_be - AArch64 (big endian)
  aarch64 - AArch64 (little endian)
  arm64_32 - ARM64 (little endian ILP32)
  arm64 - ARM64 (little endian)
```

We want to compile for RISC-V, so we can choose either `riscv64` or `riscv32`, depending on whether we want to target a 64-bit or 32-bit architecture. For this exercise, we'll go with `riscv64`.

Next, we need to choose a target CPU architecture. MOJO can similarly print a list of supported CPU architectures with the `mojo build --print-supported-cpus` command, we just need to supply the triple we want to target as an argument:

```bash
 uv run mojo build --print-supported-cpus --target-triple=riscv64-unknown-linux-gnu
Available CPUs for target riscv64-unknown-linux-gnu:
  an-erbium
  andes-ax25
  andes-ax45
  andes-ax45mpv
  andes-nx45
  et-soc1
  generic-rv64
  mips-p8700
  rocket-rv64
  sifive-p450
  sifive-p470
  sifive-p550
  sifive-p670
  sifive-p870
  sifive-s21
  sifive-s51
  sifive-s54
  sifive-s76
  sifive-u54
  sifive-u74
  sifive-x280
  sifive-x390
  spacemit-a100
  spacemit-x60
  spacemit-x100
  syntacore-scr3-rv64
  syntacore-scr4-rv64
  syntacore-scr5-rv64
  syntacore-scr7
  tt-ascalon-x
  veyron-v1
  xiangshan-kunminghu
  xiangshan-nanhu
  xt-c910v2
  xt-c920v2
```

We'll simply go with `generic-rv64` for this exercise.

So our build command to compile our `hello.mojo` file to RISC-V machine code will look like this:

```bash
uv run mojo build hello.mojo --target-triple=riscv64-unknown-linux-gnu --target-cpu=generic-rv64 --emit=asm
```

This should produce an assembly file named `hello.s` in the same directory as our `hello.mojo` file. This assembly file will contain the RISC-V assembly code generated by the MOJO compiler for our `hello.mojo` program.
